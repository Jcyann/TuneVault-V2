---
name: Lamancusa key verification
description: Source hierarchy for correcting imported Lamancusa tune keys.
---

For tunes imported from John Lamancusa’s collection, use the exact title-matched
collection page or its score as the primary authority for the stored key. Use
the printed key heading or score’s tonal center/key signature; do not treat
cross-tuning text as a key by itself. External catalogs resolve only collection
entries without a readable key.

**Why:** Generic search results often represent a different published version
of the same tune. Exact collection notation preserves the key of the actual
arrangement represented in TuneVault.

**How to apply:** Require a strong normalized-title match. If a collection
score and an external listing conflict, retain the collection score’s key
unless there is evidence that it is not the same arrangement. Keep genuine
B-flat and modal/minor values distinct from B major.
